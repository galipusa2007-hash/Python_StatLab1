# Lab01 · ИнфоХимия — статистический анализ ферментативного гидролиза крахмала

Лабораторная работа № 1 по математической статистике.

Исследование ферментативного гидролиза крахмала свободной и иммобилизованной на мезопористом TiO₂ глюкоамилазой. Анализ основан на экспериментальных данных оптической плотности при длине волны 580 нм, полученных йод-крахмальным методом.

## Экспериментальные данные

Используются два исходных набора данных: оптическая плотность реакционных смесей и результаты исследования степени гидролиза крахмала.

Основной набор содержит 588 значений оптической плотности, организованных в 196 троек.

В анализ включены все три значения каждой тройки, в том числе вычисленные по формулам. При статистической интерпретации учитывается, что вычисленные значения не являются независимыми экспериментальными повторностями.

Для каждой тройки рассчитываются описательные статистики, включая среднее значение оптической плотности.

Степень гидролиза определяется по формуле:

\[
X = 100\left(1-\frac{\overline{A}_{\mathrm{проба}}}{\overline{A}_{\mathrm{контроль}}}\right)
\]

где:

- \(X\) — степень гидролиза, %;
- \(\overline{A}_{\mathrm{проба}}\) — средняя оптическая плотность пробы;
- \(\overline{A}_{\mathrm{контроль}}\) — средняя оптическая плотность контроля.

## Исследуемые случайные величины

В работе анализируются три случайные величины:

1. Оптическая плотность контрольной пробы.
2. Оптическая плотность пробы с ферментом.
3. Степень гидролиза крахмала.

Для величин исследуются распределения, описательные статистики, свойства оценок и результаты выборочного анализа.

## Проверяемые гипотезы

**H1. Калибровка без фонового смещения**

Проверяется гипотеза о равенстве свободного коэффициента калибровочной зависимости нулю:

\(H_0: a=0\).

**H2. Стабильность оптической плотности контроля**

Проверяется предположение, что оптическая плотность контрольных проб не изменяется со временем.

**H3. Суммарная эффективность иммобилизованного фермента**

Сравнивается суммарная степень гидролиза за три последовательных цикла иммобилизованного фермента со степенью гидролиза свободного фермента.

Для каждого цикла используется средняя оптическая плотность тройки. В сравнение включаются только полные наборы с одинаковыми экспериментальными условиями: температурой, временем реакции, концентрацией крахмала и pH.

**H4. Сравнение ферментов в первом цикле**

Проверяется гипотеза о различии степени гидролиза между свободным и иммобилизованным ферментами в первом цикле при сопоставимых экспериментальных условиях.

## Статистический анализ

Ноутбук включает:

- разведочный анализ данных (EDA) и визуализацию;
- исследование распределений и нормализацию;
- оценивание статистических характеристик;
- анализ зависимости наблюдений;
- эмпирическую проверку состоятельности оценок;
- сравнение выборочных и генеральных статистик;
- выборки с возвращением и без возвращения;
- проверку четырёх статистических гипотез;
- поправку Холма на множественные проверки;
- генератор случайных чисел и сравнение его характеристик с экспериментальными данными.

Статистические выводы основаны на результатах расчётов, представленных в Jupyter Notebook.

## Запуск проекта

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить JupyterLab:

```bash
jupyter lab lab01_sprint1.ipynb
```

В Jupyter Notebook выполнить все ячейки последовательно.

Для автоматической проверки:

```bash
python -m jupyter nbconvert \
  --to notebook \
  --execute lab01_sprint1.ipynb \
  --output /tmp/lab01_checked.ipynb
```
