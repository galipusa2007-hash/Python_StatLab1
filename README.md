# Lab01 · ИнфоХимия — спринт 1

Статистическое исследование ферментативного гидролиза крахмала глюкоамилазой — свободной и иммобилизованной на мезопористом TiO₂ — по данным йод-крахмального метода (ОП при 580 нм).

## Структура

```
lab01_sprint1.ipynb        ноутбук спринта 1 (структура по ТЗ, выполнен, с графиками)
labtools/                  пакет с кодом, который вызывает ноутбук
  data.py                  загрузка CSV (десятичная запятая), разметка экспериментов, серий и троек, пересчёт X
  validation.py            проверка данных: вычисленные повторности, сверка «Табличек», формула «Погрешности»
  stats_tools.py           описательные статистики, подбор распределений, тесты, состоятельность, выборки
  plots.py                 единый стиль графиков
data/raw/                  исходные файлы, не изменяются
  od_statistika_list1.csv          = «Статистика - Лист1.csv» (оптическая плотность)
  hydrolysis_tablichki_list2.csv   = «Таблички - Лист2.csv» (степень гидролиза)
data/processed/            производные таблицы, их пересоздаёт ноутбук
  od_measured.csv          392 измеренных значения ОП (позиции 1–2 каждой тройки)
  od_pairs.csv             196 условий: A₁, A₂, среднее, SD, D = ln(A₁/A₂)
  hydrolysis_recomputed.csv  142 условия: X, u(X), X по сосудам
requirements.txt           зависимости
```

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab lab01_sprint1.ipynb    # Kernel → Restart & Run All
```

Полный прогон занимает около минуты. Все случайные эксперименты — моделирование, бутстреп, перестановки — используют одно зерно `SEED` из `labtools/__init__.py`, поэтому результаты воспроизводятся. Проверено на Python 3.13, numpy 2.5, pandas 3.0, scipy 1.18, matplotlib 3.11, statsmodels 0.15.

## Ключевые решения по данным

- В 163 из 196 троек третье значение ОП вычислено из первых двух: среднее или 2·A₁ − A₂. Анализ ведётся по двум измеренным сосудам; исходные файлы не изменены.
- Степень гидролиза пересчитана по измеренным сосудам, X = 100 %·(1 − Āп/Āк). Погрешность — по закону распространения ошибок, с учётом разброса контроля.
- Сосуды одной серии делят ошибку приготовления растворов (ICC ≈ 0,44 у контроля). Поэтому гипотезы о систематических эффектах проверяются на уровне серий, а не отдельных точек.

## Git: как вести историю для бонуса за версионирование

ТЗ даёт бонус за итеративный подход, где по коммитам видна логика работы. Удобная последовательность коммитов:

1. `data: загрузка CSV, разметка экспериментов и троек`
2. `validation: вычисленные повторности, сверка датасета 2`
3. `rv1: ОП контроля — EDA, распределение, независимость, выборки, гипотезы`
4. `rv2: ОП проб с ферментом`
5. `rv3: степень гидролиза, распространение ошибок, гипотезы`
6. `resume: сводные таблицы, поправка Холма, литература`
